▶ 네이버증권 차트 바로가기

2. 기업 개요

[주요 사업]

▶ UI/UX 개발 플랫폼 : HTML5 웹 표준 기반 UI/UX 개발 플랫폼 '엑스빌더6(eXBuilder6)'를 개발·공급하며, 대학·공공·금융·제조 기업 업무 시스템 화면 설계를 WYSIWYG 방식으로 지원한다.

▶ 대학 ERP · SI : 대학 전용 ERP '엑스캠퍼스(eXCampus)'를 기반으로 학사·입시·일반행정·연구행정 등 대학 통합정보시스템 구축(SI) 사업을 수행한다.

▶ 디지털 헬스케어 : 미국 원격의료 자회사 사이버엠디케어(CyberMDCare)와 XR 기반 메디컬 피트니스 '티온 메디핏(T-ON MEDIFIT)'을 연계해 글로벌 디지털 헬스케어 사업을 확대하고 있다.

 

[기업 기본 정보]

▶ 기업명 : 주식회사 토마토시스템 (Tomato System Co., Ltd.)

▶ 상장 구분 : 코스닥 (KOSDAQ, 종목코드 393210)

▶ 설립일 : 2000년 10월 27일

▶ 회사 소재지 : 서울특별시 강남구 선릉로 (토마토타워)

▶ 직원수 : 약 230명 (2026년 2월 기준)

▶ 대표자 : 조길주, 이강찬 (각자 대표이사 체제)

 

[최근 시장 관심 이유]

▶ 대학 ERP 슈퍼사이클 진입 : 정부의 '글로컬대학30' 정책과 대학 통합·정보시스템 노후화 교체 수요가 겹치며 대학 ERP 시장이 슈퍼사이클에 진입, 국내 400여 개 대학 중 150여 개 이상을 고객으로 확보한 토마토시스템이 최대 수혜 기업으로 부각되고 있다.

▶ 생성형 AI 기반 UI 자동 생성 솔루션 : 자연어·스케치·이미지 입력만으로 UI 화면과 소스코드를 자동 생성하는 '엑스빌더6 아이젠(AIGen)'을 업계 최초로 출시하고, 미래에셋생명·흥국화재 등 금융권에 AI 테스트 자동화 솔루션 '아이큐봇(AIQBot)'을 잇달아 공급하며 성장 모멘텀을 확보했다.

▶ XR 헬스케어 · 미국 원격의료 사업 확장 : XR HMD 기반 메디컬 피트니스 '티온 메디핏'을 미국·메타 스토어에 정식 출시하고, 최대주주로 확보한 사이버엠디케어의 미국 시니어·메디케어 원격의료 플랫폼과 연동해 신성장 동력을 확보하고 있다.

4.사업개요

 

[핵심 사업]

▶ 솔루션 (엑스빌더6 · 엑스캠퍼스 · 아이큐봇) :  매출 비중 약 40% 내외. HTML5 기반 UI/UX 개발 플랫폼 엑스빌더6, 대학 전용 ERP 엑스캠퍼스, AI 테스트 자동화 솔루션 아이큐봇 등을 라이선스 및 유지보수 형태로 공급하며, 대학·공공·금융·보험 고객사에 반복 매출을 창출한다.

▶ SI (시스템 통합 구축) :  매출 비중 약 50% 내외. 대학 통합정보시스템, 학사행정, 입시, 연구행정, 금융 차세대 시스템 등의 구축 프로젝트를 수행한다. 최근 원광대(69억), 전북대, 미래에셋생명, 흥국화재 등 대형 수주가 이어지고 있다.

▶ 컨설팅 · 디지털 헬스케어 :  개발 컨설팅, ISP/BPR, EA/BI 자문과 함께 미국 사이버엠디케어(CyberMDCare) 원격의료 서비스, 티온 메디핏 XR 헬스케어 등 신성장 사업을 담당한다.


[핵심 기술력 및 기술 난도]

▶ 가상 DOM 기반 HTML5 UI/UX 개발 플랫폼 '엑스빌더6' :  HTML5 웹 표준과 가상 DOM 기술을 결합해, 복잡한 업무 화면을 드래그앤드롭 방식(WYSIWYG)으로 설계하고 표준화된 코드를 자동 생성한다. 개발·배포·운영 전 과정이 하나의 스튜디오에서 완결되는 것이 특징이다.

▶ 타사 대비 차별점 : 국산 UI 플랫폼 중 유일하게 대학 ERP · 금융권 차세대 등 대형 SI에서 실제 레퍼런스를 확보했고, 가상 DOM 기반 렌더링 성능이 경쟁사 대비 우수하다.

▶ 기술 난도 : 다양한 브라우저·OS 호환성, 대용량 데이터 그리드 처리, 접근성(WA) 준수 등 국제 웹 표준 대응 역량이 필요해 신규 진입이 어렵다.

 

▶ 생성형 AI 기반 UI 자동 생성 '엑스빌더6 아이젠(AIGen)' :  자연어 문서, 회의록, 스케치, 이미지 등 다양한 입력으로부터 UI 화면 설계와 소스코드를 자동 생성하는 생성형 AI 솔루션이다. 개발자와 비전문가 모두 사용할 수 있도록 설계됐다.

▶ 타사 대비 차별점 : UI 플랫폼과 생성형 AI를 결합한 것은 업계 최초 사례로, 자체 UI 컴포넌트 라이브러리와 프롬프트 엔지니어링을 결합해 실제 실행 가능한 코드를 산출한다.

▶ 기술 난도 : LLM 파인튜닝, UI 컴포넌트 그래프 매핑, 코드 검증 자동화 등 복합 기술이 요구되며 자체 UI 플랫폼을 보유해야 구현이 가능하다.

 

▶ AI 테스트 자동화 솔루션 '아이큐봇(AIQBot)' :  정적 테스트(코딩 표준 실시간 검증)와 동적 테스트(테스트 케이스 자동 생성·커버리지 확장)를 지원해, 개발부터 운영까지 소프트웨어 품질관리 전 과정을 자동화한다.

▶ 타사 대비 차별점 : 소스코드 영향 분석과 테스트 산출물 자동 생성을 동시에 지원해, 금융권 차세대 프로젝트의 품질 관리 시간과 비용을 획기적으로 절감할 수 있다.

▶ 기술 난도 : 정적 · 동적 테스트 알고리즘과 대규모 코드베이스 분석 엔진이 필요하며, 금융권 규제 대응 레퍼런스가 필수적이라 진입장벽이 높다.


[신규 사업]

▶ 미국 원격의료 · XR 헬스케어 (사이버엠디케어 + 티온 메디핏) :  미국 사이버엠디케어 지분 51%를 확보해 65세 이상 메디케어·메디케이드 대상 원격의료 서비스를 제공하고, XR HMD 기반 메디컬 피트니스 '티온 메디핏'을 연동해 재활·홈트레이닝 시장을 공략한다.

▶ 금융권 AI 테스트 자동화 확대 :  미래에셋생명, 흥국화재, KIDB, KB라이프 등 금융권 차세대 프로젝트에 아이큐봇을 잇따라 공급하며, 공공·SI 시장까지 확대할 계획이다.

► 대학 ERP · 통합정보시스템 : 슈퍼사이클 진입, 국내 대학 시장 절반 이상 장악

국내 대학 ERP 시장은 2000년대 초 도입된 1세대 시스템의 노후화 교체 수요와 정부의 '글로컬대학30' 정책, 대학 통합·구조조정 이슈가 겹치면서 슈퍼사이클에 진입했다. 시장 규모는 2024년 기준 연 2,000억원 수준에서 2028년 3,500억원 규모로 성장, CAGR 약 15% 수준이 예상된다. 토마토시스템은 국내 400여 개 대학 중 150여 개 이상을 고객사로 확보해 시장 점유율 1위를 유지하고 있으며, 원광대(69억), 전북대, 고려대 등 대형 수주를 이어가고 있다.

► 생성형 AI · 로우코드 UI 자동화 : 자연어로 UI 생성, 개발 생산성 10배 시장 개화

가트너는 글로벌 로우코드·노코드 개발 플랫폼 시장이 2024년 320억 달러에서 2028년 800억 달러 규모로 CAGR 25% 이상 성장할 것으로 전망하고 있다. 여기에 생성형 AI를 결합한 AI 코딩·UI 생성 시장은 별도로 CAGR 40%대의 초고속 성장이 예측된다. 토마토시스템의 '엑스빌더6 아이젠(AIGen)'은 자체 UI 플랫폼과 생성형 AI를 결합한 국내 최초 솔루션으로, 미래에셋생명·흥국화재 등 금융권 차세대 프로젝트에 채택되며 본격 매출화 단계에 진입했다.

► 디지털 헬스케어 · XR 메디컬 피트니스 : 미국 시니어 원격의료 + 재활 XR 시장 진입

미국 원격의료 시장은 2024년 350억 달러에서 2030년 1,000억 달러 규모로 CAGR 20% 이상 성장이 예상되며, 특히 65세 이상 메디케어 대상 서비스가 핵심 성장 축이다. XR 헬스케어(재활·메디컬 피트니스) 시장도 2024년 30억 달러에서 2030년 120억 달러 규모로 CAGR 25% 이상 성장이 전망된다. 토마토시스템은 미국 사이버엠디케어 최대주주(지분 51%)를 확보하고 XR HMD 기반 '티온 메디핏'을 메타 스토어를 통해 23개국에 정식 출시하며, 원격의료·재활 콘텐츠를 결합한 통합 서비스로 차별화를 추진하고 있다.

 

[향후 극복 필요한 기술장벽]

► 생성형 AI 코드 신뢰성 · 검증 : 산출 코드의 정확성과 보안성 확보

생성형 AI가 산출하는 UI 코드의 정확성·보안성·접근성 준수 여부를 자동으로 검증하는 기술은 아직 업계 전반에서 초기 단계다. 특히 금융·공공 프로젝트에서는 코드 결정 근거의 설명 가능성(Explainability)과 보안 취약점 자동 스캔이 요구된다. 이 gap을 극복해야 아이젠이 대규모 SI 프로젝트의 표준 도구로 자리 잡을 수 있으며, 극복 시 개발 생산성 5~10배 향상과 프로젝트 수익성 개선이 기대된다.

► 미국 원격의료 규제 · 보험 청구 대응 : HIPAA · CMS 규제 준수와 청구 자동화

미국 원격의료 시장 진입에는 HIPAA(의료정보 보호법), CMS(메디케어·메디케이드 서비스)의 원격 진료 청구 규정, 주(州)별 의료 라이선스 규제 등 복잡한 법적·기술적 요건이 존재한다. 사이버엠디케어는 이미 미국 현지에 청구 시스템을 갖추고 있으나, 서비스 볼륨 확대에 따른 청구 자동화·결제 안정성 기술 강화가 필수다. 이를 극복해야 미국 시니어 케어 시장에서 안정적인 매출 성장이 가능하다.

► XR HMD 메디컬 콘텐츠 상용화 및 임상 근거 확보 : FDA · 임상 데이터 축적과 보험 급여 편입

티온 메디핏 등 XR HMD 기반 메디컬 피트니스·재활 콘텐츠가 미국 보험 급여(CPT 코드) 시장에 편입되기 위해서는 임상 데이터 축적, FDA 승인 여부, 의사 협회의 가이드라인 등재 등 복합 절차가 필요하다. 현재 얼리액세스 단계이므로 향후 2~3년간 임상 근거 확보와 파트너 병원 확대가 관건이며, 극복 시 구독형 SaaS 매출로 안정적인 수익 모델 확립이 가능하다.
