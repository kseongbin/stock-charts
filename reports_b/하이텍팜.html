2. 기업 개요

[주요 사업]

▶ 카바페넴계 항생제 원료의약품 : 이미페넴, 에르타페넴 등 카바페넴계 항생제 원료의약품(API)을 생산하며 매출의 약 95%를 차지하는 핵심 사업입니다.

▶ 세팔로스포린계 항생제 원료의약품 : 다양한 세팔로스포린계 항생제 원료의약품을 GMP 규정에 따라 생산하여 완제 제조사에 공급합니다.

▶ 글로벌 API 수출 : 유럽·아시아·남미 등지의 완제 제조사에 원료의약품을 수출하며 매출의 99.95%를 해외에서 창출하는 수출 특화 기업입니다.

[최근 시장 관심 이유]

▶ 신임 CEO 체제 출범 : 창업주 김정수 전 대표에 이어 2025년 5월 차현준 신임 대표이사가 취임하며 경영진 교체가 이루어졌습니다. 신임 대표는 생산 안정화·글로벌 시장 확대·수익성 회복을 핵심 과제로 제시했습니다.

▶ 카바페넴계 항생제 수요 확대 : 다제내성균 확산으로 최후의 항생제로 불리는 카바페넴계 수요가 지속 증가하고 있어, 원료의약품 전문업체인 하이텍팜의 장기 성장성이 주목받고 있습니다.

▶ FDA 승인 기반 미국 시장 진출 : 2021년 충주공장이 FDA 승인을 획득하며 글로벌 최대 규제시장인 미국에 정식 진출한 상태로, 향후 매출 다변화의 핵심 축으로 기대되고 있습니다.

4.사업개요

 

[핵심 사업]

▶ 카바페넴계 항생제 원료의약품 :  이미페넴·에르타페넴 등 카바페넴계 항생제의 원료의약품(API)을 생산하여 완제의약품 제조사에 공급하는 핵심 사업으로, 2024년 매출 669억원(비중 95.3%)을 기록했습니다. 중환자실에서 사용되는 최후의 항생제 계열로 다제내성균 감염 치료에 필수적입니다.

▶ 세팔로스포린계 항생제 원료의약품 :  세팔로스포린계 항생제 원료의약품을 생산하는 부문으로, 2024년 매출 약 18억원을 기록했으며 카바페넴계 대비 매출 비중은 낮으나 사업 다각화 축을 담당합니다.

▶ 글로벌 API 수출 사업 :  매출의 99.95%를 해외에 공급하는 수출 특화 구조로, 유럽 비중이 87.37%에 달하며 최대주주 ACS Dobfar를 통한 유럽 유통망을 활용해 안정적 매출을 확보합니다.


[핵심 기술력 및 기술 난도]

▶ 카바페넴 전용 GMP 생산 기술 :  카바페넴계 항생제는 GMP 규정상 다른 항생제와 교차 생산이 불가능해 전용 생산라인이 필요합니다. 하이텍팜은 이 전용 생산시설과 무균 공정 노하우를 확보한 국내 유일 전문업체입니다.

▶ 타사 대비 차별점 : 경쟁사 대비 수율이 우수하고 불순물 함유율이 낮은 생산기술을 보유하고 있어 규제시장에서 품질 경쟁력을 확보하고 있습니다.

▶ 기술 난도 : 카바페넴 화합물은 구조가 불안정해 합성 조건 통제가 까다롭고, 무균 API 생산에는 첨단 격리 설비와 오랜 공정 경험이 필수적이어서 신규 진입장벽이 매우 높습니다.

 

▶ 글로벌 규제 대응 및 인증 확보 역량 :  미국 FDA cGMP, 유럽 EDQM CEP, 국내 식약처 등 주요 규제기관의 원료의약품 승인을 모두 확보한 몇 안 되는 국내 API 기업입니다. 각국 실사·심사 대응 노하우가 축적되어 있습니다.

▶ 타사 대비 차별점 : 국내 카바페넴 API 업체 중 FDA 승인을 획득한 사례가 드물어 미국 규제시장 접근성 측면에서 독보적 지위를 확보하고 있습니다.

▶ 기술 난도 : 규제기관 실사는 원료 합성·정제·품질관리 전 공정의 문서화와 검증을 요구해 통과가 어렵고, 승인 이후에도 정기 실사가 지속됩니다.

 

▶ 무균 주사제용 API 생산 기술 :  주사제용 무균 원료의약품 생산은 미세 오염도 허용되지 않는 초정밀 공정으로, 하이텍팜은 무균 이미페넴/실라스타틴 등의 상업 생산 실적을 보유하고 있습니다.

▶ 타사 대비 차별점 : 원 개발사인 미국 MSD 및 대만 Savior와 함께 세계적으로 소수만 참여하는 무균 카바페넴 시장에서 검증된 공급자 지위를 확보하고 있습니다.

▶ 기술 난도 : 무균 API 생산은 클린룸 설비, 격리 필링 기술, 엄격한 미생물 관리가 요구되어 초기 투자와 운영 난도가 매우 높습니다.


[신규 사업]

▶ 미국 시장 확대 :  2021년 FDA 승인 이후 미국 시장에 진출한 에르타페넴을 중심으로 미주 지역 매출 확대를 추진하고 있으며, 지역 편중 리스크 완화의 핵심 축입니다.

▶ 신규 카바페넴 파이프라인 확대 :  메로페넴 등 추가 카바페넴 계열 원료 개발과 신규 항생제 파이프라인 확장을 통해 품목 다변화를 추진하고 있습니다.

[핵심 분야별 상세 성장성 분석]

► 글로벌 카바페넴계 항생제 시장 : 다제내성균 확산에 따른 최후 항생제 수요 확대

글로벌 카바페넴 항생제 시장 규모는 2024년 기준 약 30억달러(약 4조원) 수준으로 추정되며, 다제내성균 감염 증가로 2030년까지 연평균 4~5% 성장이 전망됩니다. 하이텍팜은 이 시장의 핵심 API 공급자로서 유럽·미국·아시아 다중 규제 승인을 확보해 성장 수혜가 가능합니다.

► 글로벌 원료의약품(API) CDMO 시장 : 서구권 공급망 재편에 따른 성장

글로벌 API/CDMO 시장은 2024년 약 2,000억달러 수준에서 2030년 3,000억달러 이상으로 확대될 것으로 예측되며 CAGR은 6~7%로 추정됩니다. 서구권의 중국·인도 API 의존도 완화 정책에 따라 한국 API 업체의 반사이익이 기대됩니다.

► 미국 항생제 API 시장 : FDA 승인 기반 미주 진출 성장

미국은 세계 최대 항생제 시장으로 규모가 연간 100억달러 이상이며, 카바페넴계 원료의약품 수요도 지속 확대되고 있습니다. 2021년 하이텍팜 충주공장 FDA 승인 이후 에르타페넴 미국 진출이 본격화되었으며, 유럽 편중 구조를 완화할 신성장 축으로 기대됩니다.

 

[향후 극복 필요한 기술장벽]

► 중국 업체 저가 공세 대응 : 원가 경쟁력 확보 필요

중국 API 업체들은 대규모 설비와 정부 보조를 바탕으로 카바페넴 API 시장에 저가 공세를 지속하고 있으며, 2024년 하이텍팜 실적 감소의 주요 원인으로 지목되었습니다. 하이텍팜은 품질·규제 우위로 대응하고 있으나 원가 절감을 위한 공정 개선과 자동화 확대가 필요합니다.

► 품목 다변화 및 신규 파이프라인 확보 : 단일 계열 리스크 완화

현재 매출의 95% 이상을 카바페넴 단일 계열이 차지하고 있어 계열 특유의 시장 변동과 특허 만료·가격 하락에 취약합니다. 신규 계열 GMP 승인까지 통상 3~5년이 소요됩니다.

► 가동률 정상화 및 수익성 회복 : 생산 최적화 과제

2025년 1분기 기준 충주·대소 사업장 가동률이 62% 대에 머물러 있어 고정비 부담이 커진 상태입니다. 신임 대표 체제에서 생산 안정화와 수주 확대를 통한 가동률 회복이 최우선 과제이며, 이를 달성하지 못할 경우 영업 레버리지 하락으로 수익성 회복이 지연될 수 있습니다.
