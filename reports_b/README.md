# 기업분석 보고서 인덱스 (B 계정)

B 루틴(회사 계정)이 자동 생성한 보고서 목록입니다.

## 사용 방법
1. 아래 표에서 원하는 기업의 **Raw** 링크 클릭
2. `Ctrl+A` → `Ctrl+C` (전체 복사)
3. 티스토리 글쓰기 → **HTML 모드** 전환 → `Ctrl+V` 붙여넣기 → 발행
