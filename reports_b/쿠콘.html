2. 기업 개요

[주요 사업]

▶ 데이터 서비스 : 국내외 2,500여 개 금융·공공·실물 기관의 데이터를 수집·정제·표준화하여 300여 종의 API 상품 형태로 기업 고객에게 제공하는 사업이다. 마이데이터, 대출비교, 신분증 진위확인 등에 활용된다.

▶ 페이먼트 서비스 : 실명 가상계좌, 간편결제, 펌뱅킹 등 결제 인프라 API를 제공하는 사업이다. 오픈뱅킹·은행 오픈API·펌뱅킹 3가지 결제망을 단일 API로 통합 제공한다.

▶ 글로벌 결제 및 AI MCP 신사업 : 알리페이·위챗페이·유니온페이 등 글로벌 결제사 제휴와 AI 에이전트용 MCP(Model Context Protocol) 데이터 사업을 신규 성장동력으로 육성 중이다.

 

[기업 기본 정보]

▶ 기업명 : 주식회사 쿠콘 (COOCON Co., Ltd.)

▶ 상장 구분 : 코스닥 (KOSDAQ, 종목코드 294570)

▶ 설립일 : 2006년 12월

▶ 회사 소재지 : 서울 영등포구 영신로 220 (영등포동8가, KnK디지털타워) 19층

▶ 직원수 : 약 200여명 (2025년 기준)

▶ 대표자 : 김종현

 

[최근 시장 관심 이유]

▶ AI MCP 데이터 사업 본격화 : 2026년 7월 비즈니스 데이터 플랫폼 '쿠콘닷넷'에 AI 활용 데이터 전문관을 신설하고 MCP 상품 30종을 오픈했다. 연내 100여 종으로 확대하고 2027년까지 전 상품 MCP 제공을 계획하며 AI 에이전트 시대의 표준 데이터 허브를 지향한다.

▶ 글로벌 결제·스테이블코인 사업 진출 : 알리페이·위챗페이·유니온페이 제휴 확대와 CPN(Circle Payments Network) 가입을 통한 USDC·USDT 기반 스테이블코인 결제 사업을 추진 중이다. 싱가포르 법인 설립도 준비하고 있다.

▶ 안정적 수익성 유지 : 2026년 1분기 매출은 전년 대비 다소 감소했으나 영업이익률 27.9%로 높은 수익성을 유지했다. 데이터 부문 영업이익률 32.5%, 페이먼트 부문 23.6%로 균형 잡힌 실적 흐름을 보이고 있다.

4.사업개요

 

[핵심 사업]

▶ 데이터 서비스 :  2024년 매출의 약 50%를 차지하는 핵심 부문으로 개인정보·기업정보·글로벌·공공 API 등 250여 종의 데이터 상품을 제공한다. 마이데이터 사업자, 대출비교 플랫폼, 자산관리앱, 세무·회계 SaaS 등이 주요 고객이다.

▶ 페이먼트 서비스 :  간편결제, 실명 가상계좌, 펌뱅킹 등 결제 인프라를 API로 제공하며 2024년 실명 가상계좌 매출이 20% 성장했다. 오픈뱅킹·은행 오픈API·펌뱅킹 3가지 결제망을 단일 API로 통합 제공하는 하이브리드 방식이 특징이다.

▶ 비즈니스 API 스토어 (쿠콘닷넷) :  국내 최대 B2B API 스토어를 운영하며 1,600여 개 기업 고객이 사용하고 있다. 온라인에서 API 상품을 검색·구매·연동할 수 있는 One-Stop 플랫폼이다.


[핵심 기술력 및 기술 난도]

▶ 데이터 스크래핑·표준화 엔진 :  은행·증권·카드·공공기관 등 이질적 시스템으로부터 데이터를 자동 수집·파싱·표준화하는 자체 엔진을 15년 이상 축적해 왔다. 40여 개국 2,500여 기관에서 5만 종에 달하는 데이터를 실시간 수집한다.

▶ 타사 대비 차별점 : 국내에서 데이터 API와 결제 인프라를 동시 운영하는 유일한 사업자로, 데이터·결제를 결합한 원스톱 서비스가 가능하다.

▶ 기술 난도 : 기관마다 상이한 인증·암호화·화면 구조를 모두 파악해 안정적으로 유지 관리해야 하므로 진입장벽이 매우 높다.

 

▶ 하이브리드 결제 인프라 :  오픈뱅킹·은행 오픈API·펌뱅킹 3개 결제망을 단일 API로 묶어 상황별 최적 경로로 결제를 라우팅하는 기술이다. 오픈뱅킹 수수료 수준의 낮은 원가로 계좌 기반 간편결제를 지원한다.

▶ 타사 대비 차별점 : 3망을 통합 제공해 장애 시에도 대체 결제로 자동 전환이 가능하며 결제 안정성이 높다.

▶ 기술 난도 : 은행별 서로 다른 API 규격·장애 패턴을 실시간 감지하고 대체 라우팅하는 로직이 필요해 다년간 축적된 운영 노하우가 필수다.

 

▶ MCP 기반 AI 데이터 허브 :  AI 에이전트가 외부 데이터·시스템을 직접 조회·활용할 수 있도록 연결 방식을 표준화한 MCP 규격으로 데이터를 재구성한 신규 기술이다. 기존 API 자산을 AI 친화 형태로 전환한다.

▶ 타사 대비 차별점 : 국내 최대 규모 API 자산을 이미 보유하고 있어 MCP 전환 시 상품 카탈로그의 완결성에서 압도적 우위를 가진다.

▶ 기술 난도 : AI 에이전트가 오해 없이 도구를 선택·호출하도록 스키마·메타데이터를 설계해야 해 신규 프로토콜에 대한 이해와 데이터 정제 역량이 요구된다.


[신규 사업]

▶ 글로벌 결제 및 스테이블코인 :  알리페이·위챗페이·유니온페이·인도네시아 QRIS 등 글로벌 결제 네트워크 제휴와 CPN 가입을 통한 USDC·USDT 기반 스테이블코인 결제 사업을 추진한다.

▶ AI MCP 데이터 사업 :  2026년 7월 쿠콘닷넷에 AI 활용 데이터 전문관을 신설하고 MCP 상품 30종을 오픈, 2027년까지 전 상품 MCP 제공을 목표로 한다.

[핵심 분야별 상세 성장성 분석]

► 마이데이터·금융 API 시장 : 데이터 기반 금융 서비스의 표준 인프라 부상

국내 마이데이터 시장은 2022년 본격 개시 후 사업자가 60여 곳으로 확대되며 API 호출량이 연간 수억 건 규모로 성장했다. 글로벌 오픈뱅킹·API 이코노미 시장은 2024년 약 250억 달러에서 2030년 700억 달러 규모로 CAGR 약 20%(Grand View Research 등 추정)의 고성장이 전망된다. 쿠콘은 국내 최대 API 자산과 스크래핑 인프라를 기반으로 이 시장의 표준 데이터 공급자 지위를 유지하고 있다.

► 간편결제·가상계좌 시장 : 이커머스 확대와 실명 계좌 수요 증가

국내 간편결제 시장은 2024년 일평균 약 1조원 규모로 팽창했고, 실명 가상계좌 서비스는 자금세탁방지(AML) 규제 강화와 함께 이커머스·증권·가상자산 사업자 수요가 급증하고 있다. 쿠콘은 2024년 가상계좌 매출이 20% 성장하며 페이먼트 부문의 새로운 성장축으로 자리 잡았다. 향후 스테이블코인 결제 등 신결제 수단으로 확대 여력이 크다.

► AI 에이전트·MCP 데이터 시장 : 신생 프로토콜 기반 데이터 허브 선점

2024년 하반기부터 Anthropic이 공개한 MCP가 사실상 AI 에이전트 표준 프로토콜로 부상하며 관련 데이터 공급 시장이 새로 형성되고 있다. 글로벌 AI 에이전트 시장은 2024년 약 50억 달러에서 2030년 500억 달러 규모로 CAGR 약 45%가 예상된다(Grand View Research). 쿠콘은 국내에서 가장 이른 시점에 MCP 상품관을 오픈해 초기 시장 선점 효과를 노린다.

 

[향후 극복 필요한 기술장벽]

► AI 에이전트 대응 데이터 품질 : 스키마·메타데이터 정교화

MCP 상품은 사람이 아닌 AI가 소비하기 때문에 도구 선택·호출 오류를 최소화하는 스키마 설계와 메타데이터 품질이 핵심이다. 현재는 30여 종 초기 카탈로그 단계로 300여 종 API 전체를 AI 친화 형태로 재정비하는 작업이 필요하다. 극복 시 국내 대다수 기업 AI 에이전트가 쿠콘 MCP 위에서 동작하는 표준 허브가 될 수 있다.

► 글로벌 결제망·스테이블코인 인프라 : 신규 지역 규제 대응력

글로벌 결제 사업은 각국 결제 규제, KYC/AML, 스테이블코인 관련 법제(미국 GENIUS Act, EU MiCA 등)를 준수해야 하며 국내 사업 대비 리스크가 크다. USDC·USDT 결제와 CPN 참여를 위해서는 컴플라이언스·레포팅 시스템 고도화가 필요하다. 극복 시 향후 3~4년 내 해외 매출 본격화라는 회사 목표 달성이 가능하다.

► 데이터 수집 방식 규제 리스크 : 스크래핑 축소와 공식 API 대체

기존 데이터 수집의 상당 부분이 스크래핑에 기반하고 있어 마이데이터 표준 API 확대나 각 기관 자체 API 정책 강화 시 일부 사업 리스크가 존재한다. 이를 극복하려면 공식 API 기반 계약 전환, 데이터 부가가치 창출(분석·결합), 해외 데이터 소스 다변화가 필요하다. 극복 시 규제 친화적 지속 가능한 데이터 플랫폼으로 재편될 수 있다.
